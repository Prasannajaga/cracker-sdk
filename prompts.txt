Implement full `vsock` host communication support for `cracker-sdk`.

Goal:
Go beyond simple Firecracker device configuration. Add:

1. Firecracker vsock device setup
2. Host-side vsock client helpers:

   * `connect`
   * `send`
   * `recv`

Keep all existing public APIs working.

Current SDK already has:

* basic VM boot
* high-level `run()`
* pause/resume lifecycle support
* snapshot create/load support
* network interface and entropy support
* `VMState` with `RUNNING`, `PAUSED`, `EXITED`
* `VMStatus`
* `FirecrackerStateError`

Do not modify SparkVM.
Keep standard-library only.

Target files to add/update:

```txt
src/crackersdk/
  vsock.py
  result.py
  vm.py
  __init__.py

examples/
  vsock.py

examples/rootfs/
  vsock/
    init.c
    build.sh
```

## Part 1: Result models

Update `result.py` with:

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class VsockResult:
    guest_cid: int
    uds_path: str
    success: bool
    error: str | None

@dataclass(frozen=True)
class VsockMessageResult:
    uds_path: str
    port: int
    bytes_sent: int
    bytes_received: int
    response: bytes
    success: bool
    error: str | None
```

Export all of these from `__init__.py`.

## Part 2: `vsock.py`

Create `src/crackersdk/vsock.py`.

It must contain two classes:

```python
class VsockAPI:
    def __init__(self, client):
        self._client = client

    def put_vsock(self, *, guest_cid: int, uds_path: str) -> None:
        ...
```

`put_vsock()` behavior:

* Validate `guest_cid` is `int` and `> 2`.
* Validate `uds_path` is non-empty.
* Resolve `uds_path` to an absolute path.
* Ensure the parent directory exists.
* Remove any stale socket file if it already exists.
* Call:

```python
PUT /vsock
{
  "guest_cid": guest_cid,
  "uds_path": resolved_uds_path
}
```

Also add:

```python
class VsockClient:
    def __init__(self, uds_path: str, timeout: float = 5.0):
        ...

    def connect(self, *, port: int) -> None:
        ...

    def send(self, data: bytes) -> None:
        ...

    def recv(self, max_bytes: int = 65536) -> bytes:
        ...

    def request(self, *, port: int, data: bytes, max_bytes: int = 65536) -> VsockMessageResult:
        ...

    def close(self) -> None:
        ...

    def __enter__(self) -> "VsockClient":
        ...

    def __exit__(self, exc_type, exc, tb) -> None:
        ...
```

Implementation notes:

* Use Python standard-library `socket`.
* Connect to Firecracker’s host-side Unix socket at `uds_path`.
* Use `socket.AF_UNIX` and `socket.SOCK_STREAM`.
* On `connect(port=...)`, connect to the UDS.
* Then send the Firecracker host-side vsock connection request header for the guest port.
* Implement the header format in the simplest compatible way for Firecracker host-initiated vsock connections.
* Keep the protocol handling isolated and clearly documented in comments.
* Raise clear exceptions on timeout and socket errors.
* `request()` should:

  * connect
  * send bytes
  * receive a response
  * close
  * return `VsockMessageResult`

Important:

* `PUT /vsock` only creates the device.
* The guest must run a vsock listener on the target port.
* Document this clearly in comments and examples.

## Part 3: Update `crackerVM`

Update `vm.py`.

Instantiate:

```python
self._vsock_api = VsockAPI(self._client)
```

Track:

```python
self._vsock: VsockResult | None = None
```

Add:

```python
def vsock_config(self) -> VsockResult | None:
    ...
```

Add:

```python
def vsock(
    self,
    *,
    guest_cid: int,
    uds_path: str,
    strict: bool = True,
) -> VsockResult:
    ...
```

Rules:

* Only before boot.
* If state is `RUNNING` or `PAUSED`, raise `FirecrackerStateError`.
* If already configured:

  * `strict=True` → raise `FirecrackerStateError`
  * `strict=False` → return existing config
* Call `VsockAPI.put_vsock`.
* Store and return `VsockResult`.

Update `run()` optional args:

```python
vsock: dict[str, object] | None = None
```

Before boot:

* If `vsock` is provided, call `self.vsock(...)`

## Part 4: Examples

Add `examples/vsock.py`.

It should:

* Use the vsock rootfs.
* Configure:

```python
vm.vsock(
    guest_cid=3,
    uds_path="/tmp/cracker-sdk-vsock-demo/vm.vsock",
)
```

* Boot the VM.
* Use:

```python
VsockClient(...).request(
    port=5000,
    data=b"ping",
)
```

* Print the response.
* Stop the VM.
* Comment that this requires a guest listener on vsock port `5000`.

## Part 5: Vsock rootfs

Add:

```txt
examples/rootfs/vsock/
  init.c
  build.sh
```

`init.c`:

* Static C program.
* Write `vsock guest started\n` to `/dev/console`.
* Create an `AF_VSOCK`, `SOCK_STREAM` socket.
* Bind to `VMADDR_CID_ANY`, port `5000`.
* Listen.
* Accept connections.
* Read request bytes.
* If request is `ping`, write `pong from guest\n`.
* Continue serving requests in a loop.

`build.sh`:

* Compile static init:

```bash
gcc -static -Os -s -o init init.c
```

* Create `rootfs.ext4`.
* Mount it.
* Copy `init` to `/init`.
* Mark it executable.
* Unmount.

Note:

* If host kernel headers do not expose `linux/vm_sockets.h`, include clear compile-error guidance.
* Document any required kernel or Firecracker vsock prerequisites.
